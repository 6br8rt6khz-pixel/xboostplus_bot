# XBoostPlusX Telegram Bot

This is the official Telegram bot for XBoostPlusX.  
It helps users interact with the project, check payment instructions, and access platform services.

## Features
- Interactive Telegram menu
- Payment instructions with formatted wallet addresses
- Admin notifications
- Always-on deployment via Render

## Deployment
The bot can be deployed using:
- Render (recommended)
- Local machine + Python environment

## Technologies
- Python 3.12+
- python-telegram-bot
- nest_asyncio
